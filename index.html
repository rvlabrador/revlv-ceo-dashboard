ℹ️ How MCP Sync Works

Claude uses the built-in Google Calendar MCP connector. When the calendar scheduled task runs, Claude fetches your latest events and saves them to data/calendar.json in this project folder.

The dashboard reads those files from the local server at http://localhost:3000 — automatically, every time it loads or you click Refresh.

No API keys. No OAuth tokens. No Google Console setup required.

🔒 SECURITY & PRIVACY
All data stays local. Your calendar data is written to your computer only — never sent to any external server. Credentials remain in your AES-256 encrypted vault.

📊 Operations KPI APIs — optional

Connect one REST endpoint per KPI category to feed the Operations carousel with live metrics. Each endpoint should return JSON [{label, value, sub, trend}] (or {"kpis":[...]}). Leave a category blank to keep its test data. All URLs and tokens are saved encrypted in your vault.

💡 trend can be "up", "down", or omitted. Endpoints are fetched with a Bearer token if you provide one. CORS must allow http://localhost:3000.
